# Предрегистрация H10M (2026-11-16 06:25 UTC) — измеренная конкуренция вместо «×2»

Шаг 1 (H10N) пройден: «стабильная» группа по классификации A (181 рынок) даёт PnL > 0 и t > 2 во
всех трёх периодах. В ноябре 8–15 это +$133/день, t 6.68; при модельном стрессе ×2 — +$50/день, t 2.97.

Стресс «×2» — константа. Здесь он заменяется измерениями по книгам тех же 181 рынков.

## Данные
Снимки книг 181 «стабильного» рынка каждые 10 минут, 12 раз (2 часа), понедельник 16 ноября с
06:30 UTC. Хранятся все уровни внутри max spread v с размерами, ставки наград на момент снимка,
min size. Для сравнения — 6 воскресных снимков 21:05–22:20 UTC (в них только Q_bid и Q_ask).
Число мейкерских адресов — по реальным мейкерским исполнениям за 7 дней (Data API v2 trades,
мейкерские строки).

## Варианты доли пула (для котировки N = rewards_min_size на лучшей цене с обеих сторон)
- M1: S-взвешенная доля против верхней границы конкуренции (Q_bid + Q_ask)/2 из книги, среднее по
  всем 18 снимкам (воскресенье + понедельник);
- M2 (определение пользователя): доля нашего объёма в resting size внутри v без взвешивания по
  расстоянию: N / (N + resting внутри v), отдельно по каждой стороне; берётся минимум сторон
  (Q_min требует обе стороны). Среднее по понедельничным снимкам;
- M3 (стресс): поминутный минимум M1 по всем снимкам — худший наблюдённый момент.

## Критерий (шаг 2.3, от пользователя)
«Стабильная» группа на 8–15 ноября, H10C (лимит 3N): чистый PnL > 0 и t > 1.5 (кластер — событие)
при M2 и при M1. M3 — справочно. Если не проходит — указывается параметр, который убивает:
доля в resting size, частота выплат или adverse selection.
