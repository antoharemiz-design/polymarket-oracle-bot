# Этап 2 — техническая база (2026-11-14)

Источники: `docs.polymarket.com` (страницы `trading/*`, `programs/*`, `api-reference/*`),
исходники `polymarket-client` 0.18.0 и `py-clob-client-v2` 1.2.2, живые запросы.

Пометки: **[запрос]** — проверено живым запросом без авторизации; **[SDK]** — подтверждено
чтением кода SDK; **[док]** — только по документации. Всё, что требует ключей (ордера,
user-канал, heartbeat, redeem, поток Chainlink TWAP), живым запросом **не проверялось**:
торговых ключей в этой среде нет.

## 1. Параметры целевого рынка (BTC 5m)

| Параметр | Значение | Статус |
|---|---|---|
| Тик / минимальный ордер | 0.01 / 5 контрактов | [запрос] `clob-markets/{condition}` |
| Комиссия | только taker: `C · 0.07 · p · (1−p)`; 1.75 цента на контракт при p=0.5 | [запрос] `fd: {r: 0.07, e: 1, to: true}` |
| Maker-рибейт | 20% комиссий, уплаченных по вашим исполнениям; выплата ежедневно, от $1 | [док] |
| **Задержка тейкера** | **250 мс**: рыночный ордер удерживается, затем проверяется заново | [запрос] `itode: true` на BTC 5m, BTC 15m, ETH 5m |
| Стаканы Up и Down | Зеркальны: 81 529 парных обновлений, 0 расхождений | [запрос] запись рекордера |
| Приём ордеров | Открывается примерно за сутки до старта окна | [запрос] |
| Liquidity rewards | Мин. размер 50, макс. спред 4.5 цента; августовская программа $1M завершена | [запрос] + [док] |
| Поток событий | ~1 200 сообщений/с на рынок, ~570 сделок за окно | [запрос] |

Задержка тейкера — ключевой факт для стратегии. У мейкера есть 250 мс, чтобы снять котировку
после движения спота, прежде чем её исполнит быстрый тейкер. Это согласуется с исчезновением
taker-edge у `GoodFallen` (Этап 1) и делает защиту «снять при движении спота» реализуемой
без колокации.

## 2. Требования → интерфейсы

| Требование | Интерфейс | Статус |
|---|---|---|
| Стакан и сделки | `wss://ws-subscriptions-clob.polymarket.com/ws/market`, подписка `{"assets_ids": [...], "type": "market"}`; события `book`, `price_change`, `last_trade_price`; текстовый `PING` каждые 10 с | [запрос] |
| Свои ордера и сделки | `UserSpec` в `AsyncSecureClient.subscribe()`; после переподключения — сверка через `list_open_orders` и `list_account_trades` | [SDK] |
| Подпись ордера | EIP-712, выполняет SDK; локально ~4 мс на ордер | [SDK], время — замер |
| Аутентификация | L1 (подпись ключом) → API-ключ; L2 — HMAC-заголовки; SDK выводит ключ сам | [SDK] |
| Тип кошелька | Deposit Wallet (с 04.05.2026), Proxy, Safe, EOA; SDK определяет по `wallet` | [док] |
| Gasless | Relayer API key: `RelayerApiKey(key, address)` | [SDK] |
| Post-only лимитный | `place_limit_order(..., post_only=True)`; при пересечении спреда ордер отклоняется | [SDK] |
| GTD | `expiration=`; минимум 3 минуты вперёд, фактически истекает на минуту раньше | [док] |
| Рыночный FAK/FOK | `place_market_order(order_type="FAK")` | [SDK] |
| Пакет ордеров | `post_orders`, 1–15 ордеров; результат проверяется по каждому | [док] |
| Отмена | `cancel_order`, `cancel_orders`, `cancel_market_orders`, `cancel_all`; ответ содержит `canceled` и `not_canceled` с причиной | [SDK] |
| Dead-man switch | `send_order_heartbeat` каждые 5 с; после 10 с тишины сервер отменяет все ордера ключа. Отключить нельзя | [SDK] |
| Merge / redeem | `merge_positions`, `redeem_positions` через relayer | [SDK] |
| Цена разрешения | `CryptoTwapPriceSpec(["btcusd"])` — 60-секундный TWAP, требует авторизации | [SDK] |
| Изменить ордер | Невозможно: только отмена и новый ордер | [док] |

Лимиты на подписанта (тариф Standard): 40 ордеров/с (burst 60), 80 отмен/с (burst 120).
Для двух котировок на рынок это с запасом в десятки раз.

Баланс под ордера: `доступно = баланс − Σ(открытые ордера)`. Лесенка bid-ов на обеих
сторонах резервирует pUSD целиком, поэтому размер котировок ограничен капиталом напрямую.

После перезапуска матчинг-движка две минуты принимаются только post-only ордера; бот,
который ставит только post-only, этот режим проходит без изменений.

## 3. Соответствие конфигурации пользователя

Переменные из `.env.example` ложатся на новый SDK без изменений:

| `.env` | Параметр `AsyncSecureClient.create` |
|---|---|
| `POLYMARKET_PRIVATE_KEY` | `private_key` |
| `FUNDER_ADDRESS` | `wallet` |
| `POLYMARKET_RELAYER_KEY`, `POLYMARKET_RELAYER_ADDRESS` | `api_key=RelayerApiKey(key, address)` |

## 4. Задержки, измеренные из этой среды

| Операция | Значение |
|---|---|
| REST `GET /time`, keep-alive | медиана 123 мс |
| Market WS: время получения − серверная метка | медиана 57–61 мс, p90 120–149 мс |
| Разбор события SDK-потоком | 86 мкс (≈ 10% ядра при 1 200 событий/с) |

Эти цифры — верхняя граница: трафик идёт через прокси песочницы. Отмена за ~125 мс
укладывается в окно 250 мс, но с небольшим запасом; на сервере пользователя нужно измерить
заново (см. критерий Этапа 5).

## 5. Выбор стека

**Python 3.11+ / asyncio, официальный `polymarket-client` ≥ 0.18.**

- `py-clob-client-v2` из `requirements.txt` — legacy: в руководстве по миграции его
  предписано удалить вместе с `py-builder-relayer-client`. Новый SDK закрывает ордера,
  отмену, user-канал, gasless merge/redeem и поток TWAP одним клиентом.
- Скорости Python достаточно: узкое место — сеть (десятки–сотни мс), а не вычисления
  (подпись 4 мс, решение < 1 мс). Переход на Rust/Go не изменил бы порядок величины, а
  официальный Rust SDK ещё в разработке.
- Рыночные данные читаются собственным лёгким WS-клиентом (как в `recorder.py`): это
  горячий путь, и он должен работать одинаково в рекордере, бэктесте и боте.
- Спот: `wss://data-stream.binance.vision` (основной `stream.binance.com` из ряда регионов
  недоступен — здесь он отвечает 451) и Coinbase как второй источник.

## 6. Что это меняет в плане

- Бот ставит только post-only GTC и никогда не полагается на cancel/replace как на атомарную
  операцию: сначала подтверждённая отмена, потом новый ордер.
- Heartbeat включается только в боевом режиме: его нельзя отключить, и он гасит все ордера
  ключа, включая выставленные вручную.
- Защита от токсичного потока получает жёсткий бюджет времени: 250 мс от движения спота до
  подтверждённой отмены.
- Симулятор Этапа 3 обязан моделировать задержку тейкера и задержку отмены явно.
