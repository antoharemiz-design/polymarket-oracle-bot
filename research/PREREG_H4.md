# Предрегистрация H4 (2026-11-15 20:22 UTC)

Гипотеза (favorite–longshot): в спортивных рынках Polymarket до начала события покупка исходов в
определённом ценовом диапазоне как taker даёт положительный PnL к разрешению после комиссии;
маловероятные исходы систематически переоценены, фавориты недооценены.

Данные: закрытые спортивные рынки с `gameStartTime`, двумя исходами и разрешением 1/0, объём рынка
≥ $5 000, события объёмом ≥ $20 000, старт событий 1 октября – 14 ноября 2026. Сделки: Data API v2,
`taker_only=true` — каждая строка = реальная taker-сделка с ценой, которую заплатил покупатель.
Продажа исхода по p считается покупкой второго исхода по 1 − p.

Окно: только сделки не позже чем за 5 минут до `gameStartTime` (без живых данных и скоростной гонки).

Выборки:
- выбор: `gameStartTime` < 2026-10-26 00:00 UTC;
- отложенная: `gameStartTime` ≥ 2026-10-26 00:00 UTC.

Корзины цены покупаемого исхода: 0.01–0.05, 0.05–0.15, 0.15–0.30, 0.30–0.45, 0.45–0.55,
0.55–0.70, 0.70–0.85, 0.85–0.95, 0.95–0.99. PnL на контракт = выплата − цена − rate·p·(1−p);
t-статистика кластеризована по событию (исходы одного события зависимы).

Правило: стратегия «покупать исходы в корзине X до старта» выбирается на выборке выбора
(t > 2). Она проходит, если на отложенной выборке PnL > 0 и t > 2 и знак сохраняется при стрессах:
комиссия по ставке 0.07, проскальзывание +1 ц к цене покупки.
