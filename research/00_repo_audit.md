## 4. Живые параметры рынка (снимок 2026-11-13, BTC 15m)

- slug `btc-updown-15m-<unix start>`, исходы Up/Down, `resolutionSource` = `data.chain.link/streams/btc-usd-twap-60s-streams`
- tick 0.01, min size 5, спред в моменте 1 тик (0.71 / 0.72), ликвидность ≈ $15.8k
- ≈ 460 WS-сообщений/с на два токена одного рынка

## 5. Расхождения с требованиями (предварительно)

Колонка «нужно для 0x8dxd» опирается на гипотезы из постановки задачи; она будет пересмотрена после Этапа 1.

| Компонент | Что есть | Что нужно | Критичность |
|---|---|---|---|
| Запускаемость | Не компилируется, клиент вызывается несуществующим API | Рабочий код с тестами | high |
| Модель fair value | Европейский BS, страйк из timestamp, спот Binance | Страйк = цена открытия окна по Chainlink; payoff по правилам рынка; калибровка по истории | high |
| Market data | Сломанная подписка, только `book`, только top-of-book | L2-стакан с `price_change`, `last_trade_price`, метки времени | high |
| Fills / user-канал | REST-опрос, ghost fills | User WS + сверка с балансом как источником истины | high |
| Учёт PnL и комиссий | Без комиссий, без исхода экспирации | Полный учёт: fee, rebates, resolution, сверка с балансом | high |
| Бэктест / симулятор | Нет | Запись данных + симулятор очереди и задержки | high |
| Paper trading | DRY_RUN без fills | Симуляция исполнения на живом потоке | high |
| Подпись / кошелёк | EOA по умолчанию, funder не передан | `signature_type` + `funder` под тип кошелька | high |
| Merge / redeem | Вымышленный REST-эндпоинт | On-chain `mergePositions` / `redeemPositions` или relayer | high |
| Тип ордеров | GTC без post-only, SELL через спред | Post-only для котировок, FAK/FOK для хеджа | medium |
| Риск-контроль | Лимит экспозиции и дисбаланса внутри раунда | Дневной stop-loss по балансу, kill-switch по споту | medium |
| Защита от токсичного потока | Нет (z-score используется как сигнал входа) | Отмена котировок при движении спота | medium |
| Латентность | ≥ 1–2 с в контуре | Зависит от того, какой edge подтвердится в Этапе 1 | medium |
| Покрытие рынков | Только BTC 15m | BTC/ETH/SOL/XRP, 5m/15m/1h — по итогам Этапа 1 | low |
| Логирование решений | Человекочитаемые логи с эмодзи | Структурированный журнал решений с таймстемпами | medium |
