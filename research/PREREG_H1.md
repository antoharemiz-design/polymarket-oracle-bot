# Предрегистрация H1 (2026-11-15 19:50 UTC)

Гипотеза. В крипто-рынках BTC up/down 5m после окончания окна (момент сделки τ ≥ 300 с от
старта) и до разрешения исход уже определён. Покупка победителя по цене ≤ 0.99 даёт
1 − p − комиссия на контракт. Вариант H1b: в последние 15 секунд окна (285 ≤ τ < 300) покупка
стороны, которую модель (`polybot.fairvalue`, TWAP-правило) оценивает в ≥ 0.99, по цене ≤ 0.97.

Определение победителя для торговли: прокси по споту (TWAP 60 с в конце против TWAP 60 с до
старта) только при |движении| ≥ 1 б.п. (2 418/2 418 совпадений с фактическим исходом в шаге 1);
иначе рынок пропускается. Оценка PnL — по фактическому исходу.

Данные: лента всех исполнений, 2 749 рынков 3–12 ноября; время сделки = время блока − 3 с.
- выбор: рынки со стартом 3–7 ноября;
- отложенная: рынки со стартом 8–12 ноября;
- проверка исполнимости: 158 записанных рынков 14–15 ноября (стакан и сделки с мс, запись
  до +20 с после окна).

Что считается: реальные taker-покупки победителя (и продажи проигравшего) по цене ≤ 0.99 при
τ ≥ 300 + d, d ∈ {2, 5, 10} с; это объём, который ещё был доступен через d секунд после конца окна.

Критерий успеха (на отложенной выборке):
1. средний PnL на контракт после комиссии 0.07·p·(1−p) > 0, t > 2 по рынкам;
2. доступный объём при d = 5 с даёт ≥ $33 в день (нижняя граница $1K/мес) при доле захвата 25%;
3. стрессы: d = 10 с; комиссия на верхней границе (0.07 при p = 0.5 → 1.75 ц); ошибка прокси
   (рынки с |движением| < 1 б.п. исключены).
