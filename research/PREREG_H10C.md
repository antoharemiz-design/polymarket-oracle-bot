# Предрегистрация H10C (2026-11-15 21:24 UTC) — H10 с лимитом позиции, проверка на сентябре

Что обнаружено после H10/H10L. Модель без лимита позиции восстанавливала котировку N каждую минуту.
Пиковая позиция по сумме рынков: $91 306 на отложенной выборке ноября и $14 641 в октябре сверх
$10 000 / $5 308 капитала котировок. Реальный бот с $10 000 так не может. Значит, доходность на
капитал в H10 и H10L завышена.

Вариант H10C (фиксирован до просмотра сентябрьских данных, параметр не подбирается):
- лимит позиции по рынку — 3N контрактов (N = rewards_min_size). При позиции ≥ 3N бид снимается,
  при ≤ −3N снимается аск;
- пока стоит одна сторона, вознаграждение начисляется в размере 1/3 (правило Polymarket для
  одностороннего мейкера при mid в [0.10, 0.90]);
- в остальном всё как в H10: портфель из снимка 1, конфигурация «на лучшей цене», худшая модель
  исполнения, перецентровка раз в минуту, вознаграждение — среднее по снимкам 2–7;
- капитал = котировки + пиковая стоимость позиции (сумма по рынкам — верхняя граница одновременной).

Чистая проверка: сентябрь 2026, 1–30, только рынки портфеля, которые тогда торговались. Сентябрь не
использовался нигде.

Правило: чистый результат > 0, t > 2 (кластер — событие); знак сохраняется при конкуренции ×2 и
перецентровке раз в 5 минут. Для справки (не для решения) — H10C на уже просмотренных октябре
и ноябре.
