# Предрегистрация H10 (2026-11-15 21:05 UTC) — liquidity rewards вне BTC 5m

Гипотеза. Пул liquidity rewards Polymarket (на 2026-11-15 21:03 UTC — $102 396 в день на 8 564 рынка)
распределён неравномерно: на тысячах рынков в зоне начисления почти нет котировок. Двусторонняя
котировка минимального размера на таких рынках получает вознаграждение, превышающее убытки от
исполнений (adverse selection).

Почему не повторяет закрытое: rewards на BTC 5m равны $0 и закрыты; здесь — другие рынки.
Доход идёт не от места в очереди, а от времени, которое котировка стоит в зоне начисления.
Исполнения — это издержка, и для неё взята худшая для нас модель (ниже).

## Портфель (фиксируется по снимку 1, 21:03 UTC, до просмотра любых данных об исполнениях)
- Вселенная: рынки с вознаграждением; исключены live-спорт, крипто up/down, рынки, которые
  заканчиваются меньше чем через 2 суток, рынки с mid вне [0.10, 0.90].
- Котировка: двусторонняя, размер N = rewards_min_size контрактов на сторону. Две конфигурации:
  «на лучшей цене» и «на 1 тик хуже лучшей», расстояние s от mid в центах фиксировано по снимку 1.
- Оценка вознаграждения: rate × S·N / (C + S·N), S = ((v − s)/v)², C = (Q_bid + Q_ask)/2 — верхняя
  граница конкуренции по агрегированной книге.
- Отбор: рынки по убыванию rate × S·N / (C + S·N) / капитал, пока капитал не достигнет $10 000.
  Капитал на рынок — N·bid + N·(1 − ask).

## Сторона вознаграждения
Среднее по снимкам 2–7 (раз в 15 минут после снимка 1); ставки и конкуренция берутся из каждого снимка.
Арбитр — котировки, допустимые для гипотезы без очереди: вознаграждение не зависит от исполнений.
Оговорка: снимки сделаны в воскресенье вечером, в течение дня конкуренция может быть другой.
Сверка масштаба — реальные выплаты `REWARD` кошелькам мейкеров тех же рынков (Data API activity).

## Сторона издержек (реальные taker-сделки)
- Данные: taker-сделки отобранных рынков (Data API v2) и mid с шагом 1 минута (`prices-history`, fidelity 1)
  за 1–15 ноября.
- Котировка в минуту k: bid = mid(k−1) − s, ask = mid(k−1) + s (по тику), до N контрактов на сторону
  за минуту.
- Исполнение — худший для нас случай: любая taker-сделка через нашу цену исполняет нас первыми
  (мы впереди очереди). Поэтому стресс «очередь ×2» здесь неприменим: модель уже хуже него.
- PnL исполнений: переоценка позиции по mid в конце периода или по разрешению, если рынок
  разрешился раньше.

Выборки: выбор — исполнения 1–7 ноября (выбор между «на лучшей» и «на 1 тик хуже»);
отложенная — 8–15 ноября (до 21:00 UTC).

Правило: на отложенной выборке чистый результат Σ_m (вознаграждение_m × активные сутки_m −
убыток исполнений_m) > 0, t > 2 (кластер — рынок).

Стрессы, при которых знак должен сохраниться:
- конкуренция ×2;
- перецентровка котировки раз в 5 минут вместо 1 — медленный бот, перекрывает задержку 350 мс;
- комиссия мейкера 0 (по правилам), рибейт не учитывается, gas на merge/redeem $0.01 на рынок в сутки.
