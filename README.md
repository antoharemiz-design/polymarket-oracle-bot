## 🚀 Возможности

### Ядро
- **Binance Oracle** — WebSocket подключение к `btcusdt@kline_1s` для расчёта справедливой цены бинарного опциона через Black-Scholes модель
- **Directional Trading** — направленные покупки/продажи на основе расхождения рыночной и теоретической цены
- **Redeem Arbitrage** — автоматический безгазовый redeem пар YES/NO через Gasless Relayer
- **Post-Only Orders** — все ордера выставляются как лимитные (мейкер), не платите спред тейкера

### Алгоритмы
- **Kelly Criterion Sizing** — динамический размер позиции по формуле Келли
- **Multi-Level Ladder** — лесенка лимитных ордеров с настраиваемой глубиной
- **Mean Reversion** — принудительное закрытие дисбаланса при возврате z-score к среднему
- **Fallback Market Making** — симметричный маркетмейкинг при низкой уверенности модели

### Безопасность
- **Circuit Breaker** — остановка при достижении максимального убытка
- **Balance-Aware Quoting** — размер ордеров адаптируется под доступный баланс
- **Time Protection** — блокировка новых позиций перед экспирацией раунда
- **State Persistence** — сохранение позиций между перезапусками в SQLite

## 📋 Требования

### Технические
- Python **3.10+**
- Polymarket API credentials
- Binance (не требуется API ключ, только публичный WebSocket)

### Минимальный депозит

| Количество рынков | Рекомендуемый депозит | Уровень риска |
|:---|:---|:---|
| 1 рынок | $50 – $100 | Низкий |
| 2–3 рынка | $150 – $300 | Средний |
| 5+ рынков | $500+ | Высокий |

> **Важно:** Бот выставляет ордера минимум на **5 токенов** (требование Polymarket CLOB). При цене токена $0.50 один ордер требует ~$2.50. Лесенка из 3 уровней для двух токенов (YES+NO) = ~$15. Плюс резерв для манёвра.

📊 Стратегия
Основной цикл
text
1. [Binance WS] Получаем цену BTC (каждую секунду)
2. [Black-Scholes] Считаем P_fair(yes) и P_fair(no)
3. [Polymarket WS] Получаем P_market из стакана
4. [Decision] Если |P_market - P_fair| > threshold:
   ├─ P_fair > P_market + 0.03 → BUY undervalued token
   ├─ P_fair < P_market - 0.03 → SELL overvalued token
   └─ z_score < 0.3           → Mean Reversion (close imbalance)
5. [Redeem] Если накопилась пара YES+NO → redeem с прибылью
6. [Fallback] Если модель не уверена → симметричный маркетмейкинг
Режимы торговли
Режим	Триггер	Действие
🔵 Directional BUY	P_fair > P_market + 0.03, z > 0	Лимитный BUY недооценённого токена
🔴 Directional SELL	P_fair < P_market - 0.03	Лимитный SELL переоценённого токена
🟡 Mean Reversion	|z| < 0.3, есть дисбаланс	Покупка недостающего токена для пары
🟢 Fallback MM	confidence < 0.35	Лесенка лимитных BUY на оба токена
💰 Redeem	pairs ≥ 1.0	Обмен пары YES+NO → 1 USDC
🛡️ Управление рисками
Защитные механизмы
Circuit Breaker

Если общий PnL ≤ -MAX_DRAWDOWN_USDC, бот отменяет все ордера и останавливается.

Max Imbalance

Бот не покупает токен, если дисбаланс уже превысил MAX_IMBALANCE_USDC (защита от одностороннего накопления).

Balance Check

Перед отправкой ордеров проверяется доступный баланс. Ордера масштабируются под баланс.

Time Protection

Последние 15–30 секунд перед экспирацией новые позиции не открываются.

Post-Only

Все ордера выставляются с ценой best_bid + 0.01 или best_ask - 0.01, чтобы гарантированно быть мейкером.

❓ FAQ
Бот не выставляет ордера, пишет "Insufficient balance"
Причина: Сумма ордеров превышает ваш баланс.

Решение:

Пополните депозит (рекомендуемый минимум: $50–100)

Уменьшите BASE_ORDER_SIZE (до 5)

Уменьшите NUM_LEVELS (до 3)

Бот не делает redeem
Причина: Отсутствуют или неверны ключи релеера.

Решение:

Проверьте, что в .env есть POLYMARKET_RELAYER_KEY и POLYMARKET_RELAYER_ADDRESS

Убедитесь, что ключи актуальны

Проверьте, что на кошельке есть немного MATIC для газа (если релеер не работает)

Ордера отклоняются биржей
Причина: Нарушение минимальных требований CLOB.

Решение:

Минимальный размер ордера: 5 токенов

Минимальный тик цены: $0.01

Проверьте, что size >= 5 и price кратен 0.01

Что означают z-score и mispricing в логах?
z-score — на сколько стандартных отклонений текущая цена BTC отошла от скользящей средней. |z| > 2 = сильный импульс.

mispricing — разница между справедливой ценой (Black-Scholes) и рыночной ценой на Polymarket. > 0.03 = сигнал на покупку.
