# Установка polybot на VPS

Что получится:
- бот в paper-режиме работает на вашем сервере круглосуточно, после сбоя поднимается сам;
- раз в 15 минут сервер публикует `status.md` в ваш приватный репозиторий `polybot-reports`: жив ли
  бот, PnL, рынки, ошибки, последние строки лога;
- новые версии сервер ставит сам: только после прохождения тестов и с откатом, если бот не поднялся;
- ключи Polymarket сейчас не нужны. Их вводят только для live (фаза 2) и только на сервере.

Время: около 20 минут. Стоимость: сервер от ~€5 в месяц, GitHub бесплатно.

---

## Шаг 1. Арендовать сервер (5–10 минут)

Требования:

| Параметр | Значение |
|---|---|
| Система | **Ubuntu 24.04** |
| Страна | **Финляндия, Швеция, Швейцария или Австрия**. Не Германия, Нидерланды, Франция, Великобритания, США: установщик в этих странах остановится |
| Минимум | 2 ГБ памяти, 20 ГБ диска |

Где взять (цены — ориентир, проверьте на сайте):

| Провайдер | Локация | Тариф | Около |
|---|---|---|---|
| Hetzner Cloud | Helsinki (Финляндия) | CX22: 2 vCPU, 4 ГБ | €5 в месяц |
| UpCloud | Helsinki или Stockholm | 2 ГБ | €7–8 в месяц |
| Exoscale | Zurich, Geneva (Швейцария) или Vienna (Австрия) | Small | €10–15 в месяц |

При создании сервера:
- образ — **Ubuntu 24.04**;
- если умеете, добавьте свой SSH-ключ; если нет, провайдер пришлёт пароль root на почту.

Новые аккаунты Hetzner иногда просят подтвердить личность — это занимает несколько минут.

**Готово, если** в панели провайдера у сервера есть IP-адрес (например, `65.21.x.x`).

## Шаг 2. Подключиться к серверу (2 минуты)

- **Windows:** откройте PowerShell.
- **macOS:** откройте «Терминал».

Введите, подставив IP:

```bash
ssh root@65.21.x.x
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`, затем введите пароль из письма.
Hetzner при первом входе попросит сменить пароль.

Веб-консоль в браузере у провайдеров часто не поддерживает вставку текста, поэтому лучше `ssh`.

**Готово, если** видите строку вроде `root@ubuntu-4gb-hel1-1:~#`.

## Шаг 3. Установка одной командой (3–5 минут)

Скопируйте и вставьте целиком (одна строка):

```bash
curl -fsSL https://raw.githubusercontent.com/antoharemiz-design/polymarket-oracle-bot/claude/laughing-maxwell-wrv6tz/deploy/setup_vps.sh | POLYBOT_BRANCH=claude/laughing-maxwell-wrv6tz bash
```

**Готово, если** в конце видите:

```
==================================================================
 geoblock: not blocked (FI)
 provider: AS24940 Hetzner Online GmbH
 tests: passed (73)
 polybot: active (paper)
==================================================================
```

Ниже будет строка `Key: ssh-ed25519 AAAA... polybot@...` — она нужна в шаге 4.

Строку `WARNING: this IP belongs to a hosting provider` можно не трогать. Это информация: Polymarket
сейчас этот IP не блокирует, бот перепроверяет это сам. Обходить блокировку через прокси или VPN
нельзя: правила Polymarket это запрещают, и аккаунт могут заморозить.

Если установка остановилась (`STOP: ...`):

| Сообщение | Что делать |
|---|---|
| `Polymarket blocks this server's IP` | Удалить сервер, создать новый в другой стране из списка шага 1, повторить шаги 2–3 |
| `the server is in DE; the plan allows only: FI SE CH AT` | То же: выбрана не та локация |
| `Ubuntu 24.04 is required` | В панели провайдера пересоздать сервер (Rebuild) с образом Ubuntu 24.04 |
| `Polymarket geoblock check did not answer` | Подождать минуту и вставить ту же команду ещё раз |
| `build or tests failed` | Прислать мне вывод команды `tail -40 /var/lib/polybot/logs/update.log` |

Команду можно запускать повторно: настройки, ключи и данные сохраняются.

## Шаг 4. Репозиторий для статуса (3 минуты)

1. Откройте https://github.com/new:
   - Repository name: **polybot-reports** (ровно так);
   - выберите **Private**;
   - README **не** добавляйте;
   - нажмите **Create repository**.
2. В новом репозитории: **Settings → Deploy keys → Add deploy key**:
   - Title: `polybot-server`;
   - Key: строка из шага 3, начинается с `ssh-ed25519`. Если потеряли, на сервере выполните
     `cat /var/lib/polybot/.ssh/reports_ed25519.pub`;
   - поставьте галочку **Allow write access**;
   - нажмите **Add key**.

Сразу проверить можно на сервере:

```bash
sudo polybot report
```

**Готово, если** ответ `status.md published (control: run)`, а в `polybot-reports` появились
`status.md` и `control.md`. Без этой команды они появятся сами в течение 5–15 минут.

| Ответ `sudo polybot report` | Что делать |
|---|---|
| `no access to git@github.com:.../polybot-reports.git yet` | Ключ не добавлен, или репозиторий называется иначе, или он в другом аккаунте |
| `push ... failed: is 'Allow write access' ticked` | Удалить ключ в Deploy keys и добавить заново с галочкой Allow write access |

## Шаг 5. Проверка готовности

- в выводе шага 3: `tests: passed`, `polybot: active (paper)`;
- в `polybot-reports/status.md`: строка **«Бот | ✅ работает (paper)»**.

Первые ~25 минут фаза показывает `selecting`: бот выбирает рынки по 6 снимкам книги, как записано в
предрегистрации. Потом фаза меняется на `running`. С момента `running` идут официальные 48 часов
фазы 1. Сообщите мне, что `status.md` появился.

Чтобы я сам читал отчёты, дайте приложению Claude на GitHub доступ к `polybot-reports`:
github.com → Settings → Applications → Claude → Configure → Repository access → добавить
`polybot-reports`. Без этого просто присылайте мне содержимое `status.md`.

## Повседневное

| Что нужно | Как |
|---|---|
| Посмотреть статус | Открыть `status.md` в `polybot-reports` (с телефона тоже). На сервере: `polybot status` |
| Остановить | В `control.md` нажать ✏️, заменить `mode: run` на `mode: stop`, Commit changes. Сервер прочтёт в течение 5 минут и снимет все котировки |
| Остановить срочно | На сервере: `sudo polybot stop` — снимает котировки сразу |
| Возобновить | `mode: run` в `control.md`, или `sudo polybot start` |
| Обновить бота | Ничего не делать: сервер проверяет новую версию каждые 10 минут, ставит только после тестов и откатывает, если бот не поднялся |
| Логи | `polybot logs` (последние 50 строк), `polybot logs 200` |
| Тревоги в Telegram (необязательно) | `sudo polybot telegram`: команда сама объяснит, что сделать в @BotFather |

## Безопасность

- **Ключи.** В paper ключи Polymarket не нужны. В фазе 2 их вводят только на сервере командой
  `sudo polybot keys` (скрытый ввод). Хранятся в `/etc/polybot/env`, читать их могут только root и
  служебный пользователь бота. В GitHub и в Claude они не попадают.
- **Ключ сервера для GitHub** даёт запись только в `polybot-reports`, к коду и другим
  репозиториям доступа нет.
- **Права.** Бот работает от отдельного пользователя `polybot` без прав администратора. Входящих
  портов сервер не открывает.
- **Live включается только** командой `sudo polybot mode live` с подтверждением словом `LIVE`. Нужны
  ключи, ветка `main` и ответ Polymarket «не заблокирован». Каждые 10 минут бот перепроверяет
  блокировку и при блокировке снимает котировки. В live включён heartbeat Polymarket: если сервер
  умрёт, биржа сама снимет ордера.

## Что не автоматизировано и почему

- Аренда сервера и оплата — нужен ваш аккаунт у провайдера.
- Создание `polybot-reports` и добавление ключа — нужны права администратора на ваш GitHub.
- В фазе 2: пополнение кошелька Polymarket и ввод ключей — только вы и только на сервере.

## Удалить

Удалите сервер в панели провайдера. Если удаляете совсем, удалите и ключ в
`polybot-reports → Settings → Deploy keys`.
